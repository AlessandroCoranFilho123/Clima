## Funcionalidades

* **Geolocalização automática** – Detecta a posição do usuário via API do navegador; usa coordenadas de Limeira/SP como fallback caso seja negada.
* **Dados em tempo real** – Consome a [API Ninjas Weather](https://api-ninjas.com/api/weather) para obter temperatura, vento, direção e umidade atualizados.
* **Ícone dinâmico** – Alterna entre sol, nuvem e lua de acordo com o horário e a umidade.
* **Relógio ao vivo** – Hora exibida no header atualizada a cada segundo.
* **Design Responsivo** – Layout adaptável para diferentes tamanhos de tela.
* **Glassmorphism** – Uso de transparência, blur e bordas suaves para uma UI moderna.
